# 月狸 App · 安装包下载

治愈向电子日记 App「月狸」的 Android 安装包发布仓库。

## 下载

到 [Releases](https://github.com/Flowersou1/moonli-app/releases) 页面下载最新的 `moonli.apk`，传到手机直接安装。

当前正式版：**v2.0.0（原生第一版）**

- 若提示「未知来源应用」，在系统弹窗里允许安装即可
- 这是新签名的原生包，不能覆盖安装旧套壳版；请先卸载旧的「月狸」再装
- 仅支持 64 位 ARM 安卓手机
- 应用内数据保存在手机本地，卸载即清空
- 需要联网使用（对话与语音走月狸的服务端）

也可以打开网页下载页：https://moonli.duckdns.org/dl
